## CMO의 포지션

우리 유저는 **연구 성과를 SNS·기관 홈페이지에 게시해야 하는 사람**이다.
연구원 본인이거나 연구소 홍보·커뮤니케이션 담당자.
공통 맥락: **시간 압박이 있고, 결과물의 정확성에 책임을 진다.**

카드뉴스의 성공 지표는 **저장률 + 캐러셀 완주율**이다 (좋아요 ❌).
카피의 목표는 유저가 "이거 저장해야겠다"고 느끼게 만드는 것이다.

---

## 우리 목소리 (Tone of Voice)

`PRODUCT.md` 브랜드 퍼스낼리티 그대로: **명쾌 · 실용적 · 현대적**
- 연구자의 언어를 쓰되, 도구가 아닌 동료처럼
- 간결하고 직설적, 전문성은 내세우되 딱딱하지 않음

| 이다 | 아니다 |
|------|--------|
| 연구자의 동료 | AI 스타트업 과장형 |
| 팩트·수치 중심 | 감성팔이·수식어 남발 |
| 저장 유도형 훅 | 브랜드·인사말로 시작 |
| 속도+근거 둘 다 | 속도만, 또는 기술 자랑만 |

## 금지 표현 (Anti-Copy)

`PRODUCT.md` Anti-references 직결:

```
NEVER  "AI 혁신", "혁명적", "게임체인저"
NEVER  "자동으로", "알아서" (블랙박스 뉘앙스)
NEVER  기술 스택 자랑: "GPT-4", "Claude", "최신 AI"
NEVER  네온·다크·'혁신' 남발 스타일
NEVER  인사말·브랜드 자랑으로 첫 줄 낭비
NEVER  모호한 수치: "수백 명의 연구자", "엄청난 성능"
```

## 핵심 메시지 계층 (docs/19 기반)

### Hook (첫 줄, 0.5초)

**패턴 A — 손실회피** ("모르면 손해")
```
"연구 결과가 발표됐는데, 아무도 못 읽으면?"
"좋은 논문도 알려지지 않으면 읽히지 않습니다"
```

**패턴 B — 구체적 약속** ("~하는 N가지")
```
"논문 PDF → 5장 카드뉴스, 수치 오류 0"
"수치는 원문 그대로. 검증된 카드뉴스"
```

> 인사말·브랜드 소개·기능 설명으로 시작 금지. 훅이 먼저.

### Value Prop (두 번째 단)

Mirra 플레이북 + fidelity 해자:
```
패턴: [속도] + [근거 보증]
예시: "AI 초벌 → 직접 수정 → 바로 발행. 수치는 원문 출처 자동 표기."
예시: "편집 가능한 초안. 수치 하나하나 원문 페이지 확인 가능."
```

### CTA

```
강한: "논문 업로드하기", "내 논문으로 해보기"
약한 (금지): "시작하기", "알아보기", "클릭하세요"
```

## 플랫폼별 포맷

### LinkedIn (주력)

- 첫 줄 = 훅 (더보기 전 노출)
- 본문 200자 이내, 개행 많이
- 해시태그 3개 이내 (#연구자 #논문 #카드뉴스)
- 이미지: 카드뉴스 첫 장

```
예시:
좋은 논문도 알려지지 않으면 읽히지 않습니다.

PolyInsight — PDF 업로드하면 수치 검증된 카드뉴스 5장.
수치는 원문 그대로. 오류 없음.

→ [링크]

#연구자 #학술카드뉴스 #PolyInsight
```

### Instagram

- 캡션 짧게 (50자 이내)
- 훅은 카드뉴스 이미지 자체로
- 해시태그 10개 이내

### X

- 280자 이내
- 수치 1개 집중
- 스레드 불필요

## 카드뉴스 내부 카피 원칙 (S6 규율 연동)

> 출처: `docs/constitution/19_engagement_principles.md` §2

- **장당 1메시지, 30~50자** 상한 (밀도 과다 = 저장 안 됨)
- **첫 장 훅**: 손실회피 or 구체적 약속 — 추상 제목 금지
- **마지막 장 = 핵심 요약** (CTA는 캡션으로) — 저장 직접 유발
- 수치 인용 시 원문 출처 자동 표기 (= fidelity 해자)
- 수치는 원문 그대로: 94.2%를 "약 94%"로 반올림 금지
