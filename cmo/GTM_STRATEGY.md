## 초기 100명 확보 전략 (Phase 0 → Phase 1)

### 채널 우선순위

| 순위 | 채널 | 이유 |
|------|------|------|
| 1 | 연구자 개인 커뮤니티 | 직접 도달, 입소문 빠름 |
| 2 | LinkedIn | 연구자 전문 네트워크, 카드뉴스 포맷 친화적 |
| 3 | 학과/연구소 Slack/카카오톡 | 그룹 타겟, 신뢰 높음 |
| 4 | Instagram | 카드뉴스 이미지 포맷 |

### Phase 0: 씨드 유저 10명 (지금)

**목표**: 수치 오류 없는 카드뉴스 10편 생성 + 파이프라인 품질 검증

#### 전략 A — Lead Magnet (인바운드, 주력)

CTO의 코퍼스 하네스에 이미 있는 **유명 논문**으로 샘플 카드뉴스를 만들어 SNS에 공개한다.

**타겟 논문**:
- "Attention Is All You Need" (Transformer, 2017) — 역대 최다 인용 AI 논문
- "BERT: Pre-training of Deep Bidirectional Transformers" (2018)
- "Lowry 1951 단백질 정량" — 생명과학 최다 인용
- 코퍼스 내 분야별 대표 논문 (agr/med/chem/mat 각 1편)

**배포 카피 패턴**:
```
"역대 최다 인용 논문 [논문명], 카드뉴스로 만들어봤습니다.
수치는 원문 그대로입니다. 검증했습니다.

여러분의 논문도 동일한 품질로 → [링크]"
```

**왜 이게 작동하는가**:
- 유저가 이미 아는 논문 → 결과물 품질 직접 판단 가능
- 유명 논문의 바이럴 파워 활용 (연구자 커뮤니티 공유)
- 아웃바운드 DM 대비 노력 대비 도달 범위 100배

#### 전략 B — 연구실 파일럿 (아웃바운드, 보조)

- KITECH 또�� 대학 연구실 1곳, 5편 배치 생성
- Lead Magnet 샘플이 있으면 설득이 쉬워짐 → B는 A 이후에 실행

#### 수집 지표
- 수치 오류 발견 건수 (품질 검증)
- "다시 쓰고 싶은 부분" (UX 신호)
- 공유/저장 수 (바이럴 계수)

### Phase 1: 초기 100명 (MVP 배포 후)

**LinkedIn 콘텐츠 마케팅**

주 1회 포스팅 루틴:
```
1주차: 카드뉴스 샘플 공개 (특정 논문, 결과 수치 포함)
2주차: "연구자를 위한 SNS 가이드" 교육 콘텐츠
3주차: 사용 전/후 비교 (논문 PDF → 카드뉴스 5장)
4주차: 유저 사례 공유 (허락 받은 것만)
```

**타겟 커뮤니티 게릴라 마케팅**:
- 각 분야 PhD 커뮤니티 (생명, 화학, 소재, 공학)
- 게시글이 아니라 댓글로 자연스럽게 — 스팸 아님
- "이런 거 쓰시는 분 계세요?" 질문글에 답변

**연구자 인플루언서 파트너십**:
- 팔로워 1,000~10,000명 규모 "나노 인플루언서" 연구자
- 무료 크레딧 제공 → 사용 후기 자발적 공유 유도

## 핵심 성장 지표 (초기 100명 단계)

| 지표 | 목표 | 측정 방법 |
|------|------|-----------|
| 방문자 → 가입 전환율 | > 15% | 랜딩 페이지 analytics |
| 가입 → 첫 논문 업로드 | > 50% | DB 이벤트 로그 |
| 첫 업로드 → 다운로드 완료 | > 70% | job status 완료율 |
| 재방문율 (2주 이내) | > 30% | 동일 유저 재업로드 |
| 추천 의향 (NPS) | > 30 | 이메일 설문 |

## 안 하는 것 (GTM 범위 밖)

- 유료 광고 (초기에 돈 쓰지 않음 — 제품 검증 먼저)
- 일반 대중 대상 캠페인 (타겟 아님)
- PR 기사 작성 (유저 없는 홍보는 의미 없음)
- 팔로워 수 경쟁 (저장률 > 팔로워 수)

## 경쟁사 포지셔닝

| 서비스 | 강점 | 우리 차별점 |
|--------|------|------------|
| Mirra | 미려한 디자인, SNS 특화 | fidelity 없음 — 수치 오류 위험 |
| 일반 AI 카드뉴스 | 빠른 생성 | 원문 grounding 없음 |
| 직접 제작 (Canva 등) | 자유도 | 시간 비용 10x |

**우리의 해자**: 수치 출처 자동 표기 + 연구자 편집 권한 — 경쟁사가 단기에 복제 불가.
