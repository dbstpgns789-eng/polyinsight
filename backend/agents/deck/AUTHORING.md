## 3. eval 셋

정본 = `eval/eval_set.json` — 6편(재료2·CS1·바이오1·**이론1·장문1**).
이론(킬러 수치 없음)·장문(60k 절단)은 **꼬리 스트레스** — generality가 무너지는 지점을 겨냥한다.

셋 변경(논문 교체·추가)도 §2에 로그를 남긴다. 셋이 바뀌면 전후 비교가 깨지므로 **새 라벨**로 다시 찍는다.

## 4. 시각 앵커 — refs(폐기 방향) vs 논문 자신(D안)

### ⛔ 승격 루프는 폐기됐다 (2026-07-13)

2026-07-11에 "심사 통과 덱을 refs로 승격 = 복리 해자"라고 제안했다. **그 제안은 틀렸다.**

```
우리 산출물 → refs → 다음 산출물 → refs → …
```

이 루프는 모델에게 **자기 출력을 교과서로 되먹인다** — 미감의 **근친교배**다. 세대가 갈수록 분산이
줄고 한 방향으로 수렴한다. 승격 기준이 엄격할수록 **더 빨리 좁아진다**(살아남는 건 "우리 저지가
좋아하는 룩"뿐). 복리 해자가 아니라 **복리 수축**이다.

> **원칙: refs는 늘리지 않는다. 늘릴수록 좁아진다.**
> 유한한 레퍼런스로는 "논문 수만큼의 룩"에 원리적으로 도달할 수 없다 — 30 레이아웃 카탈로그를
> 폐기한 것과 정확히 같은 이유다(§1). **refs = 소프트 카탈로그.**

### 현행 refs (폐기 실험 중)

`authoring_prompts.py`의 `REF_LIBRARY` — 3개 전부 cs-ml. `AUTHOR_FEWSHOT_N=0`으로 끌 수 있다.

**유죄 증거(2026-07-12 실측)**: 산출물이 refs의 색 이름·헥스를 그대로 복사.
`#36E0CE 전기 시안` → `#3DD6D0 전기 시안`. "베끼지 마라" + "이미 보여준 방향" 헤더를 **두 겹**으로
넣었는데도 소용없었다 — 수만 토큰의 구체 시연이 문장 3줄을 이긴다.

refs를 옹호하는 유일한 논거("마감 하한 담보")는 **한 번도 검증된 적이 없다.** 그 짐은 지금
L1 하드 가드 + L2 품질 기준 + 저지가 나눠 지고 있다.

### D안 — 논문이 곧 레퍼런스 (`figures.py`, `AUTHOR_FIGURES_N`)

앵커를 **밖(남의 덱)에서 안(논문 자신)으로** 뒤집는다. 이 논문의 그림(SEM·그래프·도식)을
모델이 직접 본다. **논문마다 그림이 다르므로 동질화가 원리적으로 불가능하다.**

실측 근거: Attention 논문의 실제 시각 언어는 **파스텔**(분홍·주황·노랑) + 둥근 박스인데,
우리는 refs 때문에 **미드나잇 네온**을 입혔다 — **논문 자신을 배신한 것.**

판정 실험: `exp-D-paper-as-ref`(refs 0 + 논문 그림 3장, microbead). 결과는 §2 결정로그.
