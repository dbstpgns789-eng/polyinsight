# Table Stakes 실행 계획 — 우선순위와 완료 신호

> 2026-07-20 · 판정 틀 = `TABLE_STAKES_CUTLINE.md` · 타깃 = **개인 연구자**
> 이 문서는 **코드·문서 실측 기반**이다. 실제 브라우저 화면 감사는 §5에 미확정으로 남긴다.

---

## 1. 오늘 실측한 것

무료체험 배관이 Task 13까지 사실상 완료돼(오늘 25커밋) 화면이 안정됐으므로 감사 가능 시점에 들어왔다.

**라우트 인벤토리** — 생각보다 많다:
```
/  /login  /signup  /verify  /forgot-password  /reset-password
/onboarding  /dashboard  /deck/new  /deck/[jobId]  /editor/[jobId]
/upgrade  /privacy  /terms
```

**법무 문서 실측** — 내용이 부실하지 않다. privacy에는 개인 연구자 최상위 관문인 **기밀성 문구가 이미 있다**:
> "AI 처리: 업로드한 논문의 텍스트가 카드뉴스 생성을 위해 Anthropic API로 전송됩니다. **학습 목적으로 사용되지 않습니다.**"
> "내보내기 파일은 생성 후 24시간이 지나면 자동 삭제됩니다."

그래서 이 항목의 갭은 **"없다"가 아니라 "아무도 안 보는 곳에 있다"**로 재정의된다.

## 2. 발견된 갭 (근거 포함)

### G1. ★자가당착 — 랜딩은 단언하고 약관은 부인한다 `A × 벽전`

| 위치 | 문구 |
|---|---|
| 랜딩 히어로 | "**지어내지 않습니다.** 논문이 근거입니다" |
| 랜딩 해자 섹션 | "AI가 **지어내지 않습니다.** 원문이 근거입니다" |
| **terms 제7조** | "AI가 생성한 콘텐츠의 **정확성은 보장되지 않으며**, 서비스는 수치 검증 결과를 **참고 정보로 제공**합니다" |

**이것이 teardown 8장 2번과 정확히 같은 구조다.** 경쟁사는 "환각을 막습니다"라 광고하고 약관 7조엔 "정확성을 보장하지 않습니다"라 써서 자기 해자를 자기 약관으로 반박했다. **우리도 밟았다.**

법적 면책은 필요하다 — 문제는 **갭의 크기**다. 한쪽은 절대 단언, 다른 쪽은 전면 부인이다. 그 사이가 비어 있어서, 약관을 읽은 사람은 랜딩이 과장이라고 판단한다.

**해결 방향(승인 필요)**: 양쪽을 **우리가 실제로 하는 일**로 정렬한다. 우리가 하는 건 "지어내지 않게 만드는 것"이 아니라 **"모든 수치를 원문과 대조하고, 확인 안 된 것을 표시하는 것"**이다. 이건 단언이 아니라 검증 가능한 사실이라 약관과 충돌하지 않는다. 해자가 약해지는 게 아니라 **정확해진다** — 경쟁사가 못 하는 건 바로 이 대조다.

### G2. 기밀성 문구가 업로드 지점에 없다 `A × 벽전`

privacy엔 있는데 **`/deck/new`(파일을 놓는 그 순간)에 한 글자도 없다.** 랜딩에도 없다 — 검증은 파는데 기밀성은 안 판다.

**개인 연구자는 처리방침을 안 읽는다.** 미발표 원고를 올릴지 망설이는 순간은 업로드 화면이고, 그 화면에 문장이 없으면 없는 것이다. 조직은 계약서로 해결하지만 개인은 눈앞의 한 줄로 판단한다.

### G3. 랜딩에 "(예시)" 딱지가 붙은 지표가 노출된다 `B × 벽전`

```
98.4%  수치 원문 일치율 (예시)
```

**가짜 숫자를 지표처럼 배치했다.** teardown 지뢰 5번(데모가 실제보다 매끈하면 첫 세션에서 배신)에 해당하고, 개인 연구자에게는 오히려 역효과다 — "(예시)"를 본 사람은 *진짜 수치는 없구나*로 읽는다.

**우리는 실측치가 있다**: 12덱 실측에서 미확인 15→5, GPT-3·MMLU·CoT·ResNet·Attention 5편 전부 미확인 0. 진짜 숫자로 바꾸거나 빼는 게 낫다.

### G4. 도움말·FAQ가 없다 `B × 벽전`

문의는 `mailto:` 하나뿐. 개인 연구자가 올리기 전에 궁금한 것(어떤 논문이 되나 / 얼마 걸리나 / 내 파일 어떻게 되나 / 수정 되나 / 무료는 뭐까지)을 답하는 곳이 없다.

### G5. 로그인 없이 결과물을 보는 곳 `A × 벽전` — **판정 보류**

랜딩에 예시 카드가 있긴 하다(해자 섹션, 히어로 배지 `28.4 BLEU · 논문 7페이지 확인됨`). **충분한지는 실제 화면을 봐야 판정된다.** §5로 넘긴다.

우리는 **진짜 산출물이 있으므로 목업 없이 갤러리를 채울 수 있다** — 경쟁사가 4대 데모를 전부 목업으로 만들어 첫 세션 배신을 산 것과 반대되는 구조적 우위다.

## 3. 우선순위

### P0 — 지금 한다 (`A × 벽전`)

| # | 무엇을 | 어디에 | 왜 | 완료 신호 | 판단 |
|---|---|---|---|---|---|
| **P0-1** | 랜딩 단언 ↔ 약관 부인 정렬 | `web/src/app/page.tsx` 히어로·해자 섹션, `terms/page.tsx` 7조 | 자가당착은 신뢰를 즉사시킨다. 경쟁사가 정확히 여기서 무너졌다 | 랜딩 문구가 약관과 모순 없이 읽히고, 해자 주장이 **검증 가능한 사실**로 서술됨 | **세훈 승인 필요** (브랜드 카피) |
| **P0-2** | 업로드 지점 기밀성 한 줄 | `web/src/app/deck/new/page.tsx` 드롭존 근처 | 개인 연구자 최상위 신뢰 관문. 문장은 이미 privacy에 있어 **새로 정할 게 없다** | 업로드 화면에서 "학습 미사용 · 직접 삭제 가능"이 보이고 처리방침으로 링크됨 | **내가 그냥 함** |
| **P0-3** | "(예시)" 가짜 지표 처리 | `page.tsx` 해자 섹션 stat | 가짜 숫자는 신뢰를 깎는다. 실측치가 있는데 예시를 쓸 이유가 없다 | `(예시)` 딱지가 랜딩에서 사라짐 — 실측치로 교체 또는 제거 | **세훈 승인** (숫자 공개 여부) |

### P1 — 벽 전에 하되 P0 이후 (`A/B × 벽전`)

| # | 무엇을 | 왜 | 완료 신호 | 판단 |
|---|---|---|---|---|
| **P1-1** | 실제 브라우저 마감 감사 (§5) | 개인은 기능 부재보다 **엉성함**에서 아마추어를 감지한다 | 5화면 순회 후 죽은 링크·빈 상태·에러 카피 목록 확정 | 내가 함 |

### P2 — 벽 후 (전환 데이터 본 뒤)

- 공개 `/pricing` (지금은 `/upgrade`로 충분)
- **환불 정책 조문화** — ★결제 연동 시 **필수**. 한국 전자상거래법 청약철회권. 경쟁사는 무환불을 조문화 없이 "고객센터 문의"로 우회해 법적 지뢰를 남겼다. 우리는 결제 태스크와 **묶어서** 처리한다
- `/settings` (dead 버튼 여부 미확인)
- 재방문 훅 (롱테일)

### 안 함 (`C`) — 버렸다고 기록한다

상태 페이지 · 블로그 · 커뮤니티 · 다국어 · 시트/팀 관리 · 인보이스·세금계산서 · 보안 백서 · 외부 통합 · 모바일 앱

> **이유**: 개인 연구자는 이것들을 **찾지 않는다.** 없다고 이탈하지 않는다. 우리 규모에서 이걸 만드는 시간이 곧 차별성에 도달하지 못하는 이유가 된다. **조용히 빠뜨린 것이 아니라 의도적으로 미룬 것이다.**

## 4. 유지할 것 (이미 잘하고 있는 것 — 건드리지 않는다)

감사는 고칠 것만 찾지 않는다. **경쟁 우위인데 무심코 망가뜨릴 수 있는 것**을 먼저 고정한다.

1. **아하가 벽 앞에 있다** — 생성·뷰어·편집·검증 배지를 무료로 다 보여주고 export만 잠근다. 경쟁사는 마법을 벽 뒤에 둬서 미끼-현실 갭으로 이탈을 만들었다. **이 결정 자체가 우위다.**
2. **명시 동의 체크박스** — 경쟁사는 인라인 문장으로 마찰을 없앴다(다크패턴). 전환율보다 신뢰가 크다. 유지.
3. **워터마크 없는 순수잠금** — 저해상도 맛보기·워터마크 타협 없음.
4. **privacy 문서 품질** — 위탁처 명시(Anthropic·Resend·Google), 학습 미사용, 파기 정책. 이 수준이면 개인 연구자 기준 충분하다.

## 5. 미확정 — 실제 브라우저 감사로만 판정되는 것

코드 읽기로는 안 나오는 항목. **차가운 눈 2개**로 5화면(`/` → `/signup` → `/onboarding` → `/deck/new` → `/deck/[id]` + export 벽)을 순회한다.

- **처음 온 사람** — 30초 안에 뭐 하는 서비스인지 알겠나. 어디서 막히나. 죽은 링크·빈 화면·이상한 에러를 몇 개 밟나.
- **올릴까 망설이는 사람** — 미발표 논문을 올려도 되겠나. 이 팀이 다음 달에도 있을 것 같나. 결과물이 내 이름 걸 만한가.

확인 항목: 빈 상태(덱 0개) · 에러 카피 · 로딩/대기 화면(생성 중) · 모바일 폭 · 죽은 링크 · `/settings` 실재 여부 · 갤러리 충분성(G5).
