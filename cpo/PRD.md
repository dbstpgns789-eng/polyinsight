## 타겟 고객 페르소나

### Primary: 개인 연구자

**누구**: 박사생, 포닥, 신진 연구자 (국내 이공계 중심)
**문제**: 논문은 있는데 SNS 콘텐츠화할 시간·역량이 없다
**두려움**: AI가 수치를 틀리게 인용할까 봐 결과물을 못 믿겠다
**원하는 것**: 원문에서 검증된, 10분 안에 발행 가능한 카드뉴스

**획득 경로**: 연구자 커뮤니티(ResearchGate, 학과 Slack), LinkedIn 연구자 그룹

### Secondary: 연구소 홍보담당

**누구**: KITECH, 출연연 홍보팀, 대학 연구처
**문제**: 연구자가 직접 SNS 활동 안 함 → 성과 홍보 공백
**원하는 것**: 연구자 논문을 배치로 카드뉴스화, 기관 SNS 발행

> Secondary는 MVP에서 고려하지 않는다. v2 이후.

## 핵심 기능 (MVP 포함)

### 필수 기능 (MVP)

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| PDF 업로드 | 단일 논문 PDF 업로드 | P0 |
| 자동 파싱 | S1 텍스트 추출 + S2 섹션 파싱 | P0 |
| 카드뉴스 생성 | S6 AI 카드 JSON 생성 (원문 grounding) | P0 |
| 카드 미리보기 | 에디터에서 실시간 미리보기 | P0 |
| 컴포넌트 편집 | 필드 단위 텍스트 수정 | P0 |
| PNG 렌더 | S7 Playwright 1080×1080 PNG 생성 | P0 |
| 다운로드 | 전체 카드 ZIP 다운로드 | P0 |
| 리스크 표시 | CRITICAL/HIGH 항목 시각화 | P0 |
| 템플릿 선택 | 2종 이상 디자인 선택 | P1 |
| 자동저장 | 5초 idle 자동저장 | P1 |

### MVP에서 제외 (v2 연기)

| 기능 | 이유 |
|------|------|
| SNS 자동발행 | API 연동 복잡도, MVP 검증 전 불필요 |
| 배치 처리 (복수 논문) | 단일 논문 품질 검증이 우선 |
| 팀 협업 | 개인 연구자 우선 타겟 |
| 회원 가입/로그인 | 결제 없는 Phase 1에서 유저 데이터 수집 이유 없음. Phase 2로 이동 |
| 결제 시스템 | 유저 검증 후 |
| 폰트 선택 | 디자인 복잡도 증가 |
| 이미지 생성 AI | 수치 fidelity가 강점 — 이미지는 부가 기능 |

## 유저 플로우 (확정, 2026-06-26 수정)

```
1. 논문 PDF 업로드
   ├─ [백그라운드] S1 추출 + S6 분석 즉시 시작
   └─ [유저 화면]  업로드 즉시 템플릿 N개 선택 화면 표시
2. [사용자] 템플릿 선택 (← S6 분석은 이 시간에 완료)
3. 선택 완료 + S6 완료 → 에디터 진입 (카드 JSON 삽입)
4. 에디터: 컴포넌트 단위 수정 (optional)
5. PNG 다운로드 / (추후) SNS 자동발행
```

**핵심 UX 원칙**:
- 체감 대기 시간 = 0 — 유저는 AI 분석을 "기다리는" 경험을 하지 않는다
- S1/S6 실패 시 → 에러는 템플릿 선택 후 에디터 진입 시점에 표시 (빈 화면 이탈 방지)
- 템플릿은 S6 결과와 무관하게 항상 즉시 노출 가능

> **변경 이유**: 기존 플로우는 S6 완료 전까지 유저가 스피너만 보는 구조. S6 latency(30초~1분) 동안 템플릿 선택으로 체감 대기를 상쇄.

## 비즈니스 모델 (미확정)

### 핵심 결제 트리거 (Paywall)

> 유저가 정확히 '이것' 때문에 지갑을 연다.

| 무료 | 유료 |
|------|------|
| 월 3편, 워터마크 포함 | 무제한, 워터마크 제거 |
| 기본 템플릿 1종 | 전체 템플릿 접근 |
| PNG 다운로드만 | SNS 자동발행 (v2) |

→ **핵심 트리거**: 워터마크 제거 + 하이엔드 템플릿 접근
→ 연구자는 기관 SNS에 올릴 때 워터마크를 허용하지 않는다 → 유료 전환 동기 명확

### 옵션 A: 크레딧제

- 편당 과금 (예: 논문 1편 카드뉴스화 = 1크레딧)
- 무료 3크레딧 체험
- 장점: 낮은 진입 장벽, 사용량 비례 수익
- 단점: 크레딧 관리 시스템 개발 필요

### 옵션 B: 구독제

- 월 N편 포함 구독 (예: Basic 5편/월, Pro 무제한)
- 장점: 예측 가능한 수익, 구현 단순
- 단점: 초기 전환 장벽 높음

> 결정 시점: Beta 유저 인터뷰 후 확정. MVP는 무료 체험만.

| 단계 | 지표 | 목표값 |
|------|------|--------|
| MVP 검증 | 카드뉴스 수치 오류율 | < 5% |

| Beta | 재사용율 | > 30% (같은 유저가 2번 이상) |
| v1.0 | 유료 전환율 | > 5% |
