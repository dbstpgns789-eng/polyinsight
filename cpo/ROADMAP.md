## Deferred — v2 이후로 명시적 연기

| 기능 | 연기 이유 |
|------|-----------|
| 팀 협업 (멀티유저) | 개인 연구자 검증 먼저 |
| API 공개 | 유저 없는 API는 의미 없음 |
| 배치 처리 UI | 단일 논문 품질 > 처리량 |
| AI 이미지 생성 | fidelity 강점 희석 위험 |
| 폰트 커스터마이징 | 디자인 복잡도 증가 대비 가치 낮음 |
| 국제화 (영문) | 한국 연구자 시장 먼저 |
| 모바일 앱 | 논문 작업은 데스크탑 |
