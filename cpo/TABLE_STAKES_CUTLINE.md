# Table Stakes 컷라인 — 무엇을 갖추고 무엇을 버릴 것인가

> 2026-07-20 · 감사(Task 11 이후) **이전에 먼저 세우는 판정 틀**
> 타깃 = **개인 연구자** (2026-07-20 확정) · 기준점 = `design_reference/competitor_marketingstudios_teardown.md`

---

## 0. 왜 이 문서가 먼저인가

세훈 소신: **"시중 서비스와 거의 유사한 기능을 제공하되, 그 속에서 차별성 하나로 각각이 존재한다. 그 이후는 마케팅 영역이다."**

**절반 맞다.** 그런데 이 명제가 **자원 배분에서는 위험하게 작동한다.**

"거의 같은 기능"을 다 갖추려면 그게 곧 전부다. 갤러리·도움말·상태페이지·지원채널·요금 FAQ·약관·온보딩·빈 상태·에러 카피… 몇 달 간다. **자금 있는 팀은 병렬로 하고 우리는 순차로 한다.** 그래서 "다 갖추고 나서 차별성으로 승부"는 우리 규모에선 **차별성에 도달하기 전에 소진되는 경로**다.

그러니 감사의 산출물은 **"없는 것 50개 목록"이면 실패**다. 목록은 노이즈고, 노이즈는 결정을 못 만든다. 이 문서는 그 목록을 **자를 칼**을 먼저 만든다.

## 1. 컷라인의 두 축

모든 항목을 두 질문으로 자른다.

**축 1 — 없으면 어떻게 되나?**

| 등급 | 뜻 | 개인 연구자의 반응 |
|---|---|---|
| **A. 신뢰 게이팅** | 없으면 **못 믿는다** | "이거 올려도 되나?" → 이탈 |
| **B. 마감 일관성** | 있는데 **엉성하다** | "아마추어네" → 신뢰 하락 |
| **C. 나이스 투 해브** | 없어도 **아무도 모른다** | 무반응 |

**축 2 — 벽 전인가 벽 후인가?**

- **벽 전** = 무료 유저를 export 벽까지 데려가는 데 필요한 것 → **지금 한다**
- **벽 후** = 결제·재방문·확장에 필요한 것 → **전환 데이터 본 뒤에 한다**

> **A×벽전 = 지금 즉시. C×벽후 = 영원히 안 할 수도 있다.**

## 2. 개인 연구자 기준 — PI·기관과 뭐가 다른가

타깃이 **개인**이라 판정이 뒤집히는 항목들:

| 항목 | 개인 연구자 | (참고) PI·기관 |
|---|---|---|
| 시트 관리·팀 권한 | **C** | A |
| 인보이스·세금계산서 | **C** | A |
| SLA·상태 페이지 | **C** (아무도 안 봄) | B |
| 보안 백서·조달 문서 | **C** | A |
| **미발표 원고 기밀성** | **★A** | B (계약서로 해결) |
| 결과물 마감 품질 | **A** | B |
| 속도 체감 | **A** (10분 완성) | C |

★ **개인 연구자에게만 있는 최상위 신뢰 관문 = 미발표 원고 기밀성.**
조직은 계약서로 해결하지만 **개인은 페이지에 적힌 한 줄로 판단한다.** "업로드 파일은 학습에 쓰지 않습니다 / N일 후 자동 삭제" 같은 문장. 구현 비용은 거의 0인데 없으면 즉시 아마추어로 보인다 — 정확히 **A×벽전**이다.

## 3. 현재 인벤토리 (2026-07-20 실측)

**있는 것** (`web/src/app` 라우트):
```
/  /login  /signup  /verify  /forgot-password  /reset-password
/onboarding  /dashboard  /deck/new  /deck/[jobId]  /editor/[jobId]
/upgrade  /privacy  /terms       (/render = 내부 렌더용)
```

생각보다 많다. 인증 4종·법무 2종·온보딩·요금 안내까지 이미 서 있다.

**없는 것 (감사에서 확인할 후보)**:
- 예시 갤러리 / 둘러보기 (로그인 없이 결과물을 보는 곳)
- 도움말·FAQ
- 문의·지원 채널
- 공개 `/pricing` (지금은 `/upgrade`만)
- 계정 설정 `/settings` (메모리상 dead 버튼 — **미확인**)
- 환불 정책 (terms 안에 있을 수 있음 — **미확인**)

## 4. 컷라인 적용 (감사 전 예비 배정 — 실측으로 확정한다)

### A × 벽 전 — 지금 한다

1. **미발표 원고 기밀성 문구** — 업로드 페이지와 랜딩에 한 줄. 학습 미사용·보관 기간·삭제. *(A, 개인 연구자 최상위 관문)*
2. **약관이 해자를 반박하지 않는지** — §5 경고 ① 참조. 우리 terms 점검. *(A, 자가당착은 신뢰를 즉사시킴)*
3. **예시 갤러리 / 둘러보기** — 가입 전에 결과물을 봐야 올린다. 개인은 "이게 될까?"를 상상으로 못 넘는다. *(A, teardown 6-3 showing-not-telling)*
4. **마감 일관성 전수** — 죽은 링크·빈 상태·에러 카피·로딩. *(B지만 개인은 여기서 아마추어를 감지 → 벽 전)*

### B × 벽 전 — 감사에서 확인 후

5. 도움말·FAQ (최소 5문항: 어떤 논문이 되나 / 얼마 걸리나 / 내 파일 어떻게 되나 / 수정 되나 / 무료는 뭐가 되나)
6. 문의 채널 1개 (이메일 링크로 충분. 채팅 위젯 불필요)

### C × 벽 후 — 지금 하지 않는다

상태 페이지 · 블로그 · 커뮤니티 · 다국어 · 시트/팀 관리 · 인보이스 · 보안 백서 · 통합(Zapier 등) · 모바일 앱

> **버리는 이유를 남긴다:** 개인 연구자는 이것들을 **찾지 않는다.** 있으면 좋지만, 없다고 이탈하지 않는다. 우리 규모에선 이걸 만드는 시간이 곧 차별성에 도달하지 못하는 이유가 된다.

## 5. teardown이 준 경고 — 우리가 밟을 수 있는 지뢰 5개

경쟁사를 **기준점으로 쓰되 복사하지 않는다.** 그 보고서가 밝힌 건 **그들의 깊이가 상당 부분 분장**이었다는 것이다("28 에이전트"=CSS 연출, `agent-pipeline.live`=죽은 DNS, 마진 −39~−86%, 외부 고객 0). 표면 규율은 배우고, 주장하는 깊이는 배울 게 없다.

1. **★약관이 해자를 반박하는 자가당착** — 걔네는 "환각을 막습니다"라 광고하고 terms 7조엔 "AI 생성 콘텐츠의 정확성을 보장하지 않습니다"라 썼다. **우리 해자가 수치 검증이라 정확히 같은 함정이 가능하다.** 우리 terms를 이 각도로 읽어야 한다. *(감사 필수 항목)*

2. **마법이 벽 뒤에 앉으면 죽는다** — 걔넨 랜딩이 파는 심장(브랜드킷 자동추출)을 Free에서 못 쓰게 해서 **미끼-현실 갭**으로 이탈을 만들었다. **우리는 이미 반대로 결정했다**(아하는 벽 **앞**, 검증 배지 게이팅 금지). **이 결정을 유지하는 게 곧 경쟁 우위다.**

3. **한국 전자상거래법 청약철회권** — 걔넨 무환불을 조문화 없이 "고객센터 문의"로 우회했다(법적 지뢰). **결제를 붙이는 순간 우리도 해당된다.** → **벽 후 A항목.** 결제 연동 태스크와 묶는다.

4. **묵시 동의 다크패턴** — 걔넨 약관 동의를 체크박스가 아닌 인라인 문장으로 처리해 마찰을 없앴다. **우리는 명시 체크박스를 쓰고 있다** — 유지한다. 전환율보다 신뢰가 크다.

5. **데모가 실제보다 매끈하면 첫 세션에서 배신당한다** — 걔네 4대 데모가 전부 목업이라 실제 마찰(OAuth·10~30초 대기)과 갭이 생겼다. **우리는 실제 산출물이 있으니 갤러리를 목업 없이 진짜로 채울 수 있다** — 이게 구조적 우위다. 절대 가짜 데모를 만들지 않는다.

## 6. 앞으로의 판정 규칙

새 기능·페이지 제안이 올 때 **두 질문만 한다:**

1. **없으면 개인 연구자가 못 믿나?** (A) / 엉성해 보이나? (B) / 아무도 모르나? (C)
2. **export 벽까지 데려가는 데 필요한가?** (벽 전) / 그 뒤인가? (벽 후)

**A×벽전이 아니면 지금 하지 않는다.** 그리고 미루는 항목은 **버렸다고 기록한다** — 조용히 빠뜨린 것과 의도적으로 미룬 것은 다르다.

## 7. 감사 실행 시 (Task 11 이후)

이 틀에 **실측을 채운다.** 방법 = 차가운 눈 2개(개인 연구자 타깃이라 PI 시선은 뺀다):

- **처음 온 사람** — 30초 안에 뭐 하는 서비스인지 알겠나. 어디서 막히나. 죽은 링크·빈 화면·이상한 에러 몇 개 밟나.
- **올릴까 망설이는 사람** — 내 미발표 논문 올려도 되나. 이 팀이 다음 달에도 있을 것 같나. 결과물이 내 이름 걸 만한가.

산출물은 **순위 매긴 갭 목록**이되, 각 항목에 **①A/B/C ②벽 전/후 ③"내가 판단 없이 그냥 고쳐도 되는 것"인지** 표기한다. 마지막 항목이 중요하다 — 사소한 건 묻지 않고 고치고, **결정이 필요한 것만 모아서 한 번에** 올린다. 그래야 코어 사고가 30번 끊기지 않는다.
