# 블라인드 테스트 레퍼런스 — 왜 이게 우리 파이프라인보다 잘 나왔나

> 2026-07-04. 키토산/비타민C 논문(Carbohydrate Polymers 372, 2026)을
> **앵커 0 프롬프트**(`prompt_blind_chitosan.md`)로 클로드디자인에 던져 나온 산출물.
> 우리 파이프라인 산출(hue163 에메랄드 수렴)과 대조하려고 저장.

## 이 덱이 증명한 것

**동질화의 1범은 모델 한계가 아니라 앵커였다.**
같은 강한 모델도 브랜드 팔레트를 손에 쥐면 그 색으로 수렴하고,
아무 틀도 안 주면 **논문 대상에서 색을 유도**한다:

- 비타민C = 앰버/골드, 게·새우 껍질(키토산) = 웜 브라운·아이보리
- 팔레트: `#E4A02C`(앰버) · `#241A14`(다크 로스트) · `#FBF5EC`(아이보리 페이퍼)
- 에메랄드는 단 한 픽셀도 없음 → **주제가 색을 정하게 두면 두 논문이 절대 같은 옷을 안 입는다.**

## 저작 품질에서 배울 점 (우리 프롬프트에 반영 후보)

1. **표지 히어로 오브젝트** — CSS 그라디언트+box-shadow만으로 '비타민C 알약/태양' 구체를
   그림. 이미지 없이 라디얼 그라디언트 하나로 주제를 은유. (형태=내용)
2. **밝음↔어둠 페이싱** — 아이보리 카드(문제·구슬·결과)와 다크 로스트 카드(표지·코팅·마무리)를
   번갈아 배치해 스크롤 리듬을 만듦. 7장이 한 시리즈로 읽힘.
3. **세리프 디스플레이(Noto Serif KR / Playfair) + Pretendard 본문** — 학술 무게감.
   숫자는 `.fig`(Playfair lnum)로 크게 — `20.78%`, `193.6 mg/g` 등 수치가 주인공.
4. **모든 수치가 원문** — 2.39μm, 193.6mg/g, pH 5.5 vs 7.4, 20.78% vs 12.73%, 11.1% 감소.
   푸터에 "본문에 보고된 수치만 사용했습니다" 명시 → 우리 해자(검증)와 정확히 같은 정신.
5. **차트를 이미지가 아니라 DOM으로** — pH 방출·항균 막대를 flex+height%로 그림.
   숫자(61.3% / 88.9% 높이)가 실제 비율과 일치.
6. **체험형 카드** — 카드5(pH 방출)가 '건강한 피부 vs 자극받은 피부'를 나란한 막대로
   대비시켜, 읽지 않고 **보기만 해도** "상태 따라 조절"이 이해됨.
