# 25. AI 디자이너 정의 (정본)

> 2026-07-24 확정 · 실유저 워크스루에서 정의가 흐려 생긴 버그(0e)를 계기로 박음.
> 상태: **확정.** 구현이 이 정의를 위반하면 정의가 아니라 구현을 고친다.

## 25.0 본질 (멘탈 모델) ★

**AI 디자이너 = 온디맨드 디자이너.** 사용자가 **디자이너를 고용한 듯이** 쓰는 것.

- **사용자 모델:** 비디자이너(연구자). 디자인 토큰·CSS·레이아웃을 직접 볼 줄도 만질 줄도 모른다.
  그럴 필요도 없어야 한다.
- **사용자가 하는 일:** "이렇게 되면 좋겠다"를 **자연어로 말한다.** 결과(원하는 느낌)만 말하지,
  방법(무슨 속성을 어떻게)은 모른다.
- **우리가 하는 일:** 그 **의도와 실제 디자인 사이의 간극을 대신 메운다.** "고급스럽게" 한 마디를
  실제 그림자·간격·색·서체로 번역해 적용한다. 이게 유료 가치의 뿌리다. 디자이너를 고용하는 값.

아래 정의·불변식은 전부 이 본질에서 나온다.

## 25.1 한 줄 정의

**AI 디자이너 = 완성된 덱에 대한 자연어 편집 어시스턴트(온디맨드 디자이너).** 스타일이든
내용이든 사용자의 의도("이렇게 되면 좋겠다")를 받아, **LLM이 "작은 편집 스펙"으로 판단하고
코드가 적용한다.** 유료 가치는 **자연어 지능(의도 → 디자인 판단)**이고, **출력은 최소**다.

## 25.2 헌법 좌표

창작(생성)은 파이프라인이, 검증은 코드가, 최종판단은 사용자가(헌법 §1). AI 디자이너는
그 사이 = **생성된 덱을 사용자가 말로 다듬는 층.** 저작을 대신하지 않는다. 사용자의 미세
통제권을 자연어로 확장한다.

## 25.3 핵심 불변식: LLM 출력 = 편집 스펙, 전체 HTML 아님

진짜 구분선은 "스타일 vs 내용"이 아니라 **"AI가 무엇을 출력하느냐"**다.

- **금지:** LLM이 덱 전체 HTML을 재출력. 작은 지시("그림자 넣어")에도 7장 전체를 다시 뽑아
  느리고(3~5분, 타임아웃) 비싸고(수만 토큰) 측정 불가가 된다. (2026-07-24 실측한 버그의 뿌리.)
- **정본:** LLM은 **최소 편집 스펙만** 출력한다 = "어느 요소에 어떤 변경(CSS/텍스트)". 코드가
  그 스펙을 적용한다. 스타일이든 내용이든 동일 원칙.

이 불변식 하나가 **느림·비용·측정불가·"메리트 의심"을 한꺼번에 푼다.**

## 25.4 유료 가치(메리트) = 자연어 지능

AI 디자이너가 크레딧을 받는 이유는 **토큰 개수가 아니라 지능**이다.

- "고급스럽고 따뜻한 잡지 느낌으로" → 그림자·간격·세리프·색을 알아서 조율. 사람이 컨트롤
  10개 만질 걸 한 마디로.
- "표지만 임팩트 있게" → 크기·대비·여백을 동시에 판단.
- 프리셋 버튼이 못 하는 미묘하고 복합적인 미감.

**스타일 자연어 편집은 사용자가 가장 많이·즐겁게 쓸 곳이며, 정당한 유료 가치다.** 스타일을
LLM에서 빼자는 발상은 틀렸다(가치를 도려냄). 스타일은 남기되 출력만 최소화한다.

## 25.5 세 층 (혼동 금지)

| 층 | 무엇 | 수단 | 유료 |
|---|---|---|---|
| 원탭 프리셋 | 더 밝게·폰트 크게 등 자명한 것 | 결정적 컨트롤(LLM 없음) | 무료 (자명한 지름길) |
| **AI 디자이너** | **자연어 스타일·내용** ("고급스럽게", "제목 짧게") | **LLM → 작은 스펙 → 코드 적용** | **유료 (지능 값)** |
| 직접조작 편집기 | 이동·리사이즈·삭제 | 레이어 패널·드래그(LLM 없음) | 무료 |

프리셋 버튼은 AI 디자이너의 대체가 아니라 보완(자명한 케이스의 무료 지름길).

## 25.6 경계 (AI 디자이너가 아닌 것)

- 요소 이동·리사이즈·삭제 = 직접조작 편집기. LLM 아님.
- 새 덱 생성 = 업로드 → 생성. 편집 아님.
- 원문에 없는 수치·주장 창작 = 해자 위반. 절대 금지.

## 25.7 불변 계약

1. **충실성(해자)** — 수치는 원문 근거 안에서만. 검증 통과 후 반영.
2. **제안 → 확인** — 항상 제안 먼저, 사용자가 "적용"을 눌러야 반영. (현 구조 유지)
3. **성능 약속** — 스타일 자연어=수초, 타겟 편집=수초. 전체 재작업만 느리고, 그건 async
   진행표시(무한 스피너 금지).
4. **실패 시 무과금** — LLM 실패·취소 시 크레딧 차감 없음. (지금 charged-but-failed는 위반 → 고침)

## 25.8 경제학

작은 스펙만 출력하면 스타일 자연어 편집 = 출력 수백 토큰 = 회당 대략 $0.01~0.05. 고정단가
크레딧에 마진이 좋고, 즉시·안정·마법 같아 **크레딧 값을 한다.** 3분 스피너에 크레딧이 뜯기던
현재가 문제였지, 스타일 자연어 자체가 문제가 아니다.

## 25.10 다음 (구현으로)

이 정의를 만족하는 **"편집 스펙" 포맷 설계**가 다음 스펙. LLM이 무엇을 반환하고(예: 타겟
요소 + CSS/텍스트 변경 집합), 코드가 어떻게 적용·검증하는지. 그 위에 §25.5 세 층 라우팅과
async(전체 재작업) 처리를 얹는다.
