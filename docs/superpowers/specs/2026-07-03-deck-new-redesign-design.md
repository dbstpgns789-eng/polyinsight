# /deck/new 리디자인 — "아트디렉터에게 한마디" (브리핑 화면)

> 2026-07-03 브레인스토밍 확정. 레퍼런스: Mirra AI디자이너 패널(예시 발화 + 입력창 문법).

## 1. 화면의 목적

"새 카드뉴스" 클릭 직후 사용자 상태: 논문은 있고(콘텐츠 완성 — Mirra와의 차이),
디자인 어휘는 없고(연구자), 의심이 있다(수치 왜곡 우려).

이 화면은 설정 폼이 아니라 **위임 의식(handoff)**이다:

1. **원고 인수** — 논문 PDF를 마찰 없이 받는다 (드롭존, 구현됨 `b749ac7`)
2. **방향 위임** — "어떤 느낌"을 *선택적으로* 받는다. **비우고 눌러도 되는 게 1급 경로**
   (약속 = "AI가 알아서 발행급"). 지시는 보너스, 숙제 아님.
3. **신뢰 선불** — 생성 전에 해자를 보여준다: "원문 수치는 코드가 대조합니다"

## 2. 화면 구성 (위→아래)

```
타이틀 + 해자 캡션 (수치 대조 — accent 강조)
드롭존 히어로 (기존 — 변경 없음)
"아트디렉터에게 한마디 (선택)"
  캡션: 비우면 AI가 논문에 맞게 정합니다 · 내용은 논문이 정합니다 — 수치는 검증돼요
  💡 이렇게 말해보세요 — 예시 발화 3개 (클릭 → 입력창 삽입)
  칩 한 줄 5개 (클릭 → 풀 서술 삽입)
  자유 입력창 (textarea, placeholder: "색감, 난이도, 강조점 — 뭐든 말로 지시하세요… (비워도 됩니다)")
카드 수 슬라이더 (기존 유지)
생성 CTA (기존 유지)
```

## 3. 예시 발화 = 소프트 스키마

예문은 각각 **다른 지시 축**을 하나씩 가르친다 (코드 파싱 없이 가능성을 교육):

| 예문 | 축 |
|---|---|
| "어두운 배경에 형광 강조로, 표지는 임팩트 있게" | 색감·무드 |
| "고등학생도 이해할 수 있는 난이도로" | 타깃 독자 |
| "Table 3 결과를 표지 메인으로 강조해줘" | 강조점 |

## 4. 칩 네이밍 원칙 — 한국어 감각어

디자이너 용어 금지. 온도·재질·장소·문화 은유만 — 비전공자가 이름만 읽고 느낌이 와야 함.

- 미드나잇 네온 / **따뜻한 종이 잡지** (← "웜 페이퍼 에디토리얼" 교체) / 학교 칠판 / 지브리풍 / 깔끔한 공공기관
- 칩 클릭 → 입력창에 풀 서술 삽입: "미드나잇 네온 — 어두운 배경 + 형광 강조선" (편집 가능 텍스트 = "말로 지시" 문법 교육)

## 5. 데이터 흐름 — 분류하지 않는다 (헌법 §1)

입력창 자유텍스트 = 기존 `style` 파라미터 그대로 → S6 저작 프롬프트에 통째 주입.
**코드 파싱·카테고리 스키마 금지** — 필드 스키마 감옥 재도입(2026-06-28 교훈).
분류는 저작 모델 안에서 일어난다. "결과 부풀려줘" 같은 내용 조작 지시는 V(수치 검증)가 원문 대조로 방어 — 신규 가드 불필요.

## 6. 범위 밖 (확정)

- **비주얼 스타일 카드(B안)**: 스타일 5종 검증 후 2차
- **"내 스타일로 저장"**: 템플릿 = 사전 제작 상품이 아니라 사용자 결과물에서 태어나는 자산
  (Mirra "나만의 디자인으로" 문법). 로드맵 항목으로.
- **생성 대기 극장** (진행 단계 + 남은 시간 + 취소 — Mirra 대기화면 참조): 별도 슬라이스
- 카드 수 접기(추가 옵션화), 언어 선택: 안 함 (YAGNI)
