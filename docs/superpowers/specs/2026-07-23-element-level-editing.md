# 편집기 개별 요소 편집 (Mirra 파리티) — 스펙

> 2026-07-23 · feat/element-level-edit · 상태: **적대적 검증 대기**
> ⚠️ 작성자(9ad42573)는 이 대화에서 부분 코드 리딩으로 3회 오판했다. "현재 상태" 주장은
> 코드로 확인했으나 **런타임 미검증** — 구현 전 실제 편집기로 재확인 필수.

## 1. 의도 (사용자 목표)

- **경쟁사(Mirra) 파리티가 테이블스테이크스** — 개별 요소를 Figma/Mirra처럼 자유 선택·이동·편집.
  그 파리티를 채운 **다음** 검증(원문 대조) 차별성이 의미를 가진다. 파리티는 선택이 아니라 기본.
- 사용자 관찰: "완전 개별 요소까지 안 되는 것 같다." Mirra는 레이어 패널 + 개별 요소 편집을 지원.

## 2. 현재 상태 (코드 확인 · ⚠️런타임 미검증)

`editorAgent.ts`(origin/main, 1013줄) 정독 결과 — **이미 있는 것**:

| 기능 | 위치 | 확인 |
|---|---|---|
| **개별 리프 선택** (클릭한 요소 자체) | `pick` L48, drag L572·578 | ✅ 코드. `cardChild` **폐기**(L577 주석) |
| **개별 리프 이동/리사이즈** (블록 아님) | L578 `var el = picked` | ✅ 코드 |
| **좌표 붕괴 해결** (offsetParent-aware) | `posAncestor` L410 | ✅ 코드 (SVG·중첩 래퍼 처리, "구슬 겹침 버그" 주석) |
| **freeze-all** (진입 시 전 요소 절대배치→reflow 방지) | `freezeCard` L498 | ✅ 코드 |
| 다중선택(마퀴·shift클릭)·정렬·분배·스냅 | L518·531·580 | ✅ 코드 |
| 리사이즈 핸들·SET_RECT 수치·undo/redo·삭제·이미지 삽입·트리트먼트·텍스트 서식 | 여러 곳 | ✅ 코드 |

**→ 개별 (블록/리프) 요소 편집은 이미 상당히 구현됨.** 내가 앞서 "블록 단위만"이라 한 건 오판.

**진짜 갭 (Mirra 대비 부족):**

- **GAP-1 (inline/mixed-content 요소):** `freezeCard`가 ①inline 요소(L507) ②부모가 bare-text 또는 inline-flow 자식 가진 요소(L510)를 **승격 제외.** 이유=일부만 흐름에서 빼면 형제가 reflow로 겹침. → **제목 속 강조 span, 인라인 하이라이트는 개별 이동 시 형제가 밀림**(내 PoC에서 제목 틈 확인). 이게 "완전 개별"의 진짜 미해결.
- **GAP-2 (레이어 패널 없음):** 선택=캔버스 클릭만. Mirra식 **요소 리스트 패널**(이름·타입·선택·순서·삭제·표시토글) 부재. 발견성·정밀선택 약함.
- **GAP-3 (요소별 컨트롤 깊이):** 이미지 트리트먼트·텍스트 서식은 있으나, Mirra식 **이미지 초점/줌/교체/스톡검색을 한 패널에** 통합한 수준은 아님(부분).

## 3. 스코프

**In (이번):**
- **P1 · 레이어 패널** (GAP-2) — 카드 DOM → 편집가능 요소 리스트. 클릭 선택·호버 하이라이트·삭제·복제·순서(z-index)·이름(텍스트 발췌/태그). 캔버스 선택과 양방향 동기.
- **P2 · inline/mixed 개별 이동** (GAP-1) — 제한적. 최소: 제외된 요소를 **선택은 되게**(스타일/텍스트 편집), 이동은 "형제 안 밀리게" 처리(부모 통째 freeze 유지 + 대상만 안전 승격 or 명시적 안내).

**Out (다음 스펙):**
- GAP-3 이미지 패널 고도화(스톡검색 통합 등) — 별개 슬라이스.
- 요소 그룹핑/레이어 폴더, 애니메이션.

## 4. 접근 (설계)

### P1 레이어 패널
- **데이터 소스:** `freezeCard` 후 카드의 편집가능 요소 집합(= 이미 promote된 것 + 텍스트 리프). editorAgent가 `LAYERS` 메시지로 `[{eid, tag, kind:'text'|'image'|'shape', label, depth, z}]` 방출.
- **UI:** `DeckEditor` 옆 패널(React). 클릭→`SELECT_EID` 메시지→editorAgent가 선택+하이라이트. 역방향: 캔버스 선택→`SELECTED` eid→패널 하이라이트(이미 `data-eid` 스탬프 L83 존재).
- **조작:** 삭제(`DELETE_ELEMENT` 재사용)·복제·순서(z-index 조정 신규)·표시토글(opacity/display).

### P2 inline/mixed
- 근본이 어려움(레이아웃 물리). **안전 우선:** 제외 요소도 `pick`으로 선택은 되니 → **스타일/텍스트 편집은 허용**(이미 됨), **자유 이동은 "부모째 이동" 또는 비활성+툴팁**("이 요소는 텍스트 흐름 안이라 개별 이동 대신 서식 편집"). Mirra도 sub-word는 개별 이동 안 함(레이어=텍스트 블록 단위) — **파리티는 블록/객체 단위면 충족.**

## 5. 리스크 / 미검증 (구현 전 확인)

1. ⚠️ **현재 상태 런타임 재확인** — 실제 편집기에서 개별 리프 이동·리사이즈가 코드대로 되는지, inline span 이동 시 실제 reflow 양상. (내 3회 오판 방지)
2. `freezeCard` 후 "편집가능 요소 집합"의 정확한 경계(레이어 패널 항목) — 너무 많으면(모든 div) 패널 노이즈, 너무 적으면 누락.
3. 병렬 세션이 `editorAgent.ts`·`DeckEditor.tsx`를 동시 편집 중 → worktree 격리했으나 머지 시 충돌. 조율 필요.

## 6. 테스트 계획

- 런타임 하네스(내 PoC 확장): 실제 카드 로드→freeze→개별 리프 이동/리사이즈 무붕괴·무reflow 검증. inline span은 예상 거동 기록.
- 레이어 패널: 요소 N개 리스트↔캔버스 선택 양방향 동기, 삭제/순서 반영, serialize 생존(`data-eid`·아티팩트 제거).
- 회귀: 기존 편집(블록 이동·텍스트·이미지) 안 깨짐. `pytest`(해당 없음)·`vitest`(에디터 유닛).

## 7. ★ 확정 진단 (2026-07-23 실물 재현 — 게이트 해소)

사용자 실피드백: "텍스트만 움직이고, 이미지·SVG(구슬·식탁 이미지)는 전혀 안 움직인다. 원자 단위로
잡히고 움직였으면. 목록으로 되어 있으면 좋겠다." 실제 카드로 재현한 근본 원인:

1. **★가림(occlusion)이 1차 원인.** SVG(배경 장식) 중심을 클릭하면 그 위에 겹친 텍스트 `<span>`이
   잡힌다(`elementFromPoint`→span, not svg). 즉 **뒤에 깔린 요소는 클릭 선택 자체가 불가.**
   "안 움직인다"의 정체 = **선택이 안 됐던 것**(이동 코드는 정상). → **레이어 패널이 직접 해결**
   (목록에서 골라 선택 = 가림 우회). 사용자 "목록" 요청 = 정확한 처방.
2. **SVG 도형 CSS-무효.** SVG 루트는 `el.style.left`로 이동됨(✅ 실측 120px). 그러나 안쪽 도형
   (`<path>`·circle 등)은 x/y 속성이라 CSS left/top 무효(0px). → **선택·이동 대상 = SVG 루트**
   (안쪽 도형 아님). pick이 SVG 내부를 잡으면 루트로 승격 필요.
3. **이미지 inline 제외.** `<img>` 기본 display:inline → freezeCard L507이 승격 제외.

**우선순위 재확정:**
- **P0 (진짜 처방) = 레이어 패널** — 모든 원자 요소(텍스트블록·이미지·SVG루트·도형div) 리스트,
  목록서 선택(가림 우회)→이동/리사이즈/삭제. 사용자 복수 요청("목록"+"원자단위 선택")을 한 번에.
- **P0 동반 = 원자 선택 해소:** ①SVG는 루트 단위로 선택 ②이미지 inline 승격 허용(freeze 확장).
- **P1 = 캔버스 pick도 가려진 요소 도달**(alt+클릭 관통 등, 선택). P2(inline sub-word)는 여전히 out.

**데이터소스 결정:** 레이어 패널 요소 집합 = freeze 승격 집합과 **독립 정의**(검증기 이슈#2) —
카드 내 '의미 요소'(텍스트리프·img·svg루트·배경div)를 별도 수집. 그래야 가려진/inline 요소도 목록에 뜬다.
**eid 결정:** 패널용 전수 스탬프 필요 → serialize에서 `data-eid` **제거하도록** L802 아티팩트 목록 확장
(검증기 이슈#4 — 발행 HTML 오염 방지).
